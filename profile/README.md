# Immersive Library Experience

Two public installations that turn a collection into something you can walk up to and explore, built on one
open framework:

- **Collection Wall OpenStack 2.0** ([TU Delft Library](https://www.tudelft.nl/en/library/visit/relax-and-get-inspired/collection-wall-at-the-tu-delft-library)):
  open-access publications as an interactive wall, with room for serendipity.
- **Van muziekbibliotheek naar publieksbeleving** ([Fonos](https://fonos.nl), Beeld & Geluid):
  the music collection in context, with the newspapers of the time, in Beeld & Geluid's new music location
  in Hilversum.

| Repository | What |
|---|---|
| [collection-experience-core](https://github.com/immersive-library-experience/collection-experience-core) | the shared, reusable components |
| [collection-wall-tudelft](https://github.com/immersive-library-experience/collection-wall-tudelft) | the TU Delft Library installation |
| [collectiegebouw-muziek-in-context](https://github.com/immersive-library-experience/collectiegebouw-muziek-in-context) | the Beeld & Geluid installation |
| [lab](https://github.com/immersive-library-experience/lab) | experiments and proofs of concept |

Developed in the open: source code under MIT, all project results also under CC BY 4.0. Project leads:
TU Delft Library and Beeld & Geluid. Technical development: TangibleApp, with Trebla Technology.
